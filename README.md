# campus-event-registration

实验三已实现命令行和本地网页界面。运行环境、演示账号、业务示例与打包步骤见 [实验三使用说明](Lab_3/code/README.md)。

首次启动，在仓库目录执行以下命令。

```sh
cd Lab_3/code
make setup
make demo
```

浏览器打开 [集会活动广场](http://127.0.0.1:8000/)，演示密码为 `campus-demo`。以后在 `Lab_3/code` 执行 `make demo` 即可启动。

## 校园活动报名系统

参考大麦、猫眼、活动行等产品，至少覆盖：

- 设置参与者、组织者、检票人员和平台管理员的权限。
- 支持活动、场次、票种或报名类别的创建、审核、发布、修改和取消。
- 支持活动查询、报名、取消报名、候补和自动递补。
- 说明多人争抢最后一个名额、重复报名和截止后报名如何处理。
- 支持签到或验票，说明重复签到、缺席和活动取消如何处理。
- 支持名单导出和容量统计并保存关键操作记录。
